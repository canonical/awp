# getting-better/ — feature suggestions

One `*.md` per **feature suggestion** that would make Rust files easier to verify with
Creusot — a missing Creusot/Pearlite capability, a useful lemma or invariant template,
a tooling improvement. Filed by any `creusot-monitoring` / `creusot-sl` agent when it
hits a limitation, and **confirmed by the base-SL monitor against `L`** (the gap is
real: `creusot-sl` genuinely could not express or discharge the thing). A surprise is
*routed here, never absorbed* with a silent local workaround.

**Filename:** `YYYYMMDD-hhmm-simple-name.md` — e.g. `20260616-1547-handle-reference.md`.

**Each file should state:**
- **Trigger** — the file / `gap-N` / mission that surfaced it.
- **Observed** — what Creusot currently does (or can't do).
- **Desired** — the capability that would make verification easier/more thorough.
- **Minimal example** — the smallest Rust + Pearlite that shows the gap.
- **Guidance link** — the `U` clause it serves (e.g. "specify thoroughly").
